🧩 Prisma Schema

Use this schema:

model Threat {
  id        String   @id @default(cuid())
  ip        String
  type      String
  severity  String
  country   String?
  timestamp DateTime @default(now())
  details   String?
  score     Int?
}

model User {
  id       String @id @default(cuid())
  email    String @unique
  password String
  role     String @default("user")
}


Also create a seed.ts file with sample threats.
